КАТАЛОГ ОПТОВЫХ ЦЕН — офлайн PWA
=================================

Что в папке:
  index.html           — само приложение
  data.js              — данные прайса (название + цена по категориям)
  sw.js                — service worker (кэш для офлайн-работы)
  manifest.webmanifest — манифест PWA
  icon-192.png / icon-512.png — иконки

Как открыть на телефоне/компьютере (способы на выбор):

1) Любой бесплатный хостинг статики (GitHub Pages, Netlify Drop,
   Surge, хостинг вашего сайта). Загрузите файлы из папки как есть,
   откройте index.html — и каталог станет доступен по ссылке.
   При первом открытии браузер предложит «Добавить на главный экран».

2) Локально, без интернета: скопируйте папку на устройство и запустите
   в ней простой сервер, например:
     - Windows: установите Python с python.org, затем в папке проекта
       выполните в командной строке:  python -m http.server 8080
     - Android: приложение типа "Simple HTTP Server" из стора
   После этого откройте в браузере http://localhost:8080

Важно: если просто открыть index.html двойным кликом (file://),
каталог будет работать как обычный файл, но офлайн-режим и
«установка» PWA не включатся — это ограничение браузеров.

Как обновить цены:
  Отправьте новый прайс-файл xlsx, и data.js будет пересобран;
  остальные файлы менять не нужно. После обновления поднимите
  номер кэша в sw.js (const CACHE = 'catalog-v2' и т.д.), чтобы
  устройства скачали свежие цены.

Функции:
  - быстрый поиск по названию (регистр и «ё» не важны) и по цене;
  - фильтр по категориям, счётчики позиций;
  - сортировка: по прайсу / по алфавиту / по цене;
  - подсветка совпадений, работает офлайн.
